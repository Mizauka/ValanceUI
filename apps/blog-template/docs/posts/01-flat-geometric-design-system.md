当界面同时追求高信息密度（如小说阅读工作台、药代动力学控制台）与柔和易读的视觉节奏时，传统“圆角卡片 + 柔和阴影”往往会迅速滑向视觉噪音：重叠的投影弄脏了暖纸底面，而 6px、8px、12px 的混合圆角让工具栏显得含糊不清。

## 一、严格的三大允许几何形状

Valance 设计系统仅允许三种绝对清晰的几何原型：

1. **纯直角矩形（Pure Rectangle · `border-radius: 0`）**：负责承载结构边界、分割面板、代码画布、表头以及按钮静止态。
2. **纯正圆（Pure Circle · `border-radius: 50%` 且宽高相等）**：负责焦点与动作锚点，如活动栏激活图标、关闭按钮、主题波纹起点与空状态核心。
3. **纯胶囊（Pure Pill · `border-radius: 9999px` 或 `calc(H / 2)`）**：负责悬浮停靠条、滑动分段指示器、分类徽章以及按钮悬停形变终态。

::: warning 为什么禁止 8px 这类中等圆角？
因为当容器与子元素都使用近似的 8px 圆角时，同心边距很难保持一致；而将**结构直角**与**动作胶囊**彻底分离后，交互态（方 → 圆、方 → 胶囊）会产生极具物理辨识度的形态对比。
:::

## 二、非线性物理形变动画

我们摒弃了生硬的等比缩放，而是使用：

```css
--ease-nonlinear: cubic-bezier(0.22, 1, 0.36, 1);
--ease-expressive: cubic-bezier(0.34, 1.4, 0.64, 1);
```

悬停按钮时，圆角从 `0px` 平滑生长至精确短边半高 `calc(var(--ui-row-height) / 2)`；点击活动栏按钮时，容器从 `0%` 瞬间收束成 `50%` 纯圆。

## 三、零投影的五阶色调阶梯

没有 `box-shadow` 后，层级完全依赖色温统一の表面亮度差与 `1px` 细线完成：

- `--bg-activity`（最深层轨槽）
- `--bg-titlebar`（顶部控制栏）
- `--bg-surface`（侧边栏与卡片表面）
- `--bg-base`（中央阅读与编辑主画布）
- `--bg-elevated`（聚焦输入框与高亮容器）
