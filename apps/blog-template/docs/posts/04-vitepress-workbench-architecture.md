大多数静态博客主题只有单一的“顶部导航 + 左目录 + 正文 + 右大纲”。但在频繁查阅多篇技术笔记或小说章节时，标签页切换、正则检索与阅读排版预设会大幅提升效率。

## 架构要点

1. **会话级多标签页（TabBar）与 `Ctrl+K` 指令面板**：点击目录或文章卡片自动追加标签，支持中键关闭与保留首页固定标签，切换回来自动恢复上次阅读的 `scrollTop` 位置；按 `Ctrl+K`（或 `Cmd+K`）还能直接以关键字或正则表达式全文检索并执行快捷指令。
2. **三栏互斥双栏折叠（Dual-Pane）**：在 `769px – 1080px` 平板宽屏下，左右侧栏互斥共享同一个分屏比例 `dualSideRatio`，避免三栏同时挤占正文空间。
3. **版心宽度快照剪裁**：切换窄 / 标准 / 宽版心时使用 ViewTransition 水平 `clip-path` 剪裁过渡并锁定锚点段落。
4. **移动端 120Hz `VlSnapPager` 分页**：在移动端通过 VitePress 路由组件快照缓存与原生 `scroll-timeline` 驱动，使「首页 / 归档 / 关于」及文章切换全部保持独立滚动位置与 120fps 顺滑转场。
